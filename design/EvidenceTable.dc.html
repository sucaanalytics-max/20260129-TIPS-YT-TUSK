Subscriber deltas are quantised, not measured
Look down the Subs Δ columns: 0, 10,000, 0, 102,000. YouTube rounds each channel to the nearest thousand, so daily adds arrive in lumps. Any single day is noise; only the moving average means anything.
The channel column disappears before Feb 2026
Drag the range back past 16 Feb 2026 and the channel counts read n/a, not 0 — the series before that date is a single legacy aggregate row per day with no per-channel breakdown. A zero there would read as “the catalogue went quiet”.
